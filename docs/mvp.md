# QRコード注文システム MVP 

## 概要

飲食店のテーブルに設置されたQRコードを利用し、 客が自身のスマートフォンからメニューを注文できるシステム。

店舗スタッフは注文を確認し、 注文ステータスの変更や会計処理を行う。

##  客向け機能

- テーブルのQRコードから注文画面へアクセス
- メニュー一覧表示
- カート
- 注文
- 追加注文
- 注文履歴確認

## 店舗向け機能

- ログイン
- 注文一覧表示
- 注文商品の提供状態管理
  - 未提供 
  - 提供済み 
 - 会計処理

## 会計機能

会計時に以下の処理を行う。(実際の決済処理は行わない)

1. 現在のテーブル利用セッションの提供済み商品を取得
2. 合計金額を計算
3. 売上として保存
4. テーブル利用セッションを終了
5. 客番号をインクリメント
6. テーブルを次の客が利用可能な状態にする

## 管理機能

- メニュー登録
- メニュー編集
- 販売停止
- テーブル登録

## AIメニュー提案

客が入力した希望から注文可能なメニューを提案する。

例：

「さっぱりしたものが食べたい」

↓

RAGでメニュー情報を検索

↓

LLMを利用して候補メニューを提案
